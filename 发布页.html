它是什么样的编辑器

一个够用、安静、不联网也能干活的小工具。

算力在你本机

代码在你自己的浏览器里执行，不经过任何服务器。 JavaScript、HTML、Python 子集、C/C++ 子集开箱即跑，断网也能用。

文件树与多标签

建目录、建文件、重命名、删除。多标签编辑，带行号、语法着色、 自动缩进、括号配对、注释切换。

能中断死循环

两个自研解释器带步数上限，死循环能被掐断—— 真 CPython 和原生 JavaScript 都做不到这一点。

整包导入导出

整个工程导出成一个 .zip，换台机器再导回来。 数据在你手上，不在我们这儿。

控制台

底部面板可逐行执行 JavaScript 并看返回值，也能跑命令面板。

按需扩展

想要完整的 Python、SQLite、PHP、Ruby 甚至真 Clang？ 扩展中心里按需下载，下完存本机，之后离线可用。

装到桌面或手机

装好之后是独立窗口，断网也能写代码。

桌面（Windows / macOS / Linux）

用 Chrome 或 Edge 打开本页，点地址栏右侧的安装图标； 或者进了编辑器之后，点顶栏的「安装」按钮。

手机（iPhone / Android）

iPhone：用 Safari 打开，点底部「分享」→「添加到主屏幕」。 Android：Chrome 菜单里选「安装应用」。

离线可用

装好之后核心文件已缓存在本机，断网也能写、能跑 （JavaScript、HTML、Python 子集、C/C++ 子集）。

安装不会改变数据的存放位置——文件依然只在你这台设备上。 它只是让你不用每次开浏览器输地址。

隐私：不是承诺，是架构决定的

Code 没有服务器，所以它无法收集你的东西。以下是它不做的事：

写代码不需要注册；云盘是可选的，账号与 Chat 同一套
默认不上传你的代码与文件；云盘需你手动点按钮才传
没有统计、埋点与分析
没有 Cookie 与追踪
没有广告
不加载任何外部资源

什么时候会联网？只有这三种，而且全部默认关闭：

  • 扩展中心下载运行时：你主动点下载时，浏览器向 GitHub 发起请求 （GitHub 会看到 IP，与下载任何 GitHub 文件一样）。下载完存进本机缓存，之后离线可用。
  • 云盘同步：需你自己注册登录，开启后才会把文件传到数据库。 不用就不传 —— 默认关闭。
  • AI 辅助：需你自己填密钥，请求直连你选的服务商。 不填就没有这个入口（不是"有入口但点了报错"）。

除以上三种，页面不发任何网络请求。写代码、保存、运行都在本机完成。

本地跑一份

想连托管方都不接触，就把仓库下到本地。

git clone https://github.com/liuyiming2024/Code.git
cd Code
python3 server.py          # 打开 http://localhost:8000/

编辑与保存直接双击 index.html 就行； 但要用按需下载的运行时需要起本地服务—— 因为 file:// 下浏览器会拒绝创建 Worker。 本地与线上是同一份代码，只是给它一个正常的 http 来源。

已知限制

说在前面，免得用起来才发现。

  • JavaScript 死循环无法中断：在主线程执行，没有抢占机制， 会卡住页面，只能关闭标签页。（自研子集与 Worker 内的运行时带超时上限，能被掐断。）
  • 按需运行时未经充分真机验证：六种按需语言目前只有结构断言通过。 SQLite 与 CPython 用的是公开稳定 API；Lua / Ruby / PHP 的胶水导出形状未确认， 对不上时会报出实际导出清单而非静默失败。
  • 大文件会变卡：着色与行号是全量渲染的，几 MB 级单文件明显变慢。
  • 数据可能被浏览器清除：清浏览数据、隐私模式、配额不足都会丢。 重要内容请用「导出工程包」备份。
  • 浏览器要求：需要支持 IndexedDB 与 ES2020。
