# Code · 网页代码编辑器

一个跑在浏览器里的代码编辑器。文件存在本机，代码在本机执行，
**不依赖任何服务器、不加载任何外部资源**。

- 在线地址：https://liuyiming2024.github.io/Code/
- 源码仓库：https://github.com/liuyiming2024/Code

## 直接开始用

打开上面的网址即可，不需要注册、不需要配置。

本地使用：下载本仓库后双击 `index.html` 即可编辑与保存。

但要用**按需下载的运行时**（SQLite / Python / PHP / Ruby / C++），需要起本地服务：

```
python3 server.py          # 然后打开 http://localhost:8000/
```

因为 `file://` 下浏览器会拒绝创建 Worker。本地服务与线上是同一份实现，
只是给了它一个正常的 http 来源。

## 能做什么

| 能力 | 说明 |
|---|---|
| 文件树 | 在浏览器里建目录、建文件、重命名、删除 |
| 编辑器 | 多标签、行号、语法着色、自动缩进、括号配对、注释切换 |
| 搜索 | 在当前工程内搜文本，可区分大小写 / 全词匹配 |
| 运行 | JavaScript、HTML、Python 子集、C/C++ 子集开箱即跑；SQLite / Lua / Ruby / PHP / 完整 CPython / 真 Clang 可在扩展中心下载 |
| 控制台 | 底部面板可逐行执行 JavaScript 并看返回值 |
| 导入导出 | 整个工程导出为一个 `.zip`，也能再导回来 |

支持着色的语言：JavaScript / JSON、Python、C / C++、HTML、CSS、
Markdown、YAML、SQL、Shell。

## 关于"算力在本地"

这是本项目的核心约束，也是它和"在线 IDE"最大的区别。
**任何代码都不上传服务器**，执行只发生在你自己的浏览器里。

### 开箱就能跑（零依赖，离线可用）

| 语言 | 怎么跑 |
|---|---|
| JavaScript | 浏览器原生执行 |
| HTML | 在带 `sandbox` 限制的框架里预览，脚本可运行 |
| Python | **自研子集解释器**（`js/pylite.js`） |
| C / C++ | **自研教学级子集**（`js/cpplite.js`） |

两个自研子集**不是** CPython / GCC，能力边界写在运行面板的提示里，
遇到不支持的语法会明确报错，不静默跑歪：

- Python 子集：不支持 import 第三方库、async、生成器、装饰器
- C/C++ 子集：不支持指针与地址运算、struct / class、模板、STL、头文件与多文件

作为补偿，自研解释器带**步数上限**，死循环能被掐断——
真 CPython 和原生 JS 都做不到这一点。

### 扩展中心：按需下载真运行时

顶栏「扩展中心」里列了可选的完整运行时。**基础功能不需要下载**。

| 扩展 | 体积 | 许可证 |
|---|---|---|
| SQLite（完整 SQL 引擎） | 0.7 MB | MIT |
| Lua 5.4（Fengari，纯 JS VM） | 1.6 MB | MIT |
| QuickJS（隔离沙箱） | 0.5 MB | MIT |
| Python（完整 CPython，含标准库） | 11.9 MB | MPL-2.0 |
| PHP 8.x（Zend 引擎） | 16.7 MB | Apache-2.0 |
| Ruby（CRuby 3.3） | 33.6 MB | MIT |
| C/C++（真 Clang + LLD） | 90.2 MB | MIT |
三条必须说清楚的：

1. **首次下载需要联网**，之后存进浏览器的 Cache Storage，**离线也能用**
2. 下载时校验 SHA-256（取自 Release 资产的 `digest` 字段，不是人工抄的）
3. 加载一律放 **Web Worker**，主线程不会白屏

Python 与 C/C++ 是"**自研 + 可升级**"：子集立刻可用，
下载真运行时后自动切换到真的。两者不是替代关系，是互补——
**你始终有东西可用，下载只是让它更好。**

### 为什么不把这些塞进仓库

主仓库的约束是"零依赖、拿到就能跑、离线可用"。
这些运行时动辄几十 MB，混进去会直接破坏那条约束。
所以它们单独放在 `liuyiming2024/assets` 仓库的 Release 里，
主仓库只保留一份清单（`api/runtimes.json`）。

## AI 辅助（可选）

默认关闭。**不填密钥就完全没有 AI 请求，界面里也不出现 AI 入口。**

填了之后能做两件事：解释选中代码、按要求改写选中代码（命令面板 `Ctrl+Shift+P`）。

| 规矩 | 说明 |
|---|---|
| 密钥自备 | 你自己申请、自己付费 |
| 只存本机 | localStorage，源码里不含任何密钥 |
| 直连服务商 | 你选哪家就发给哪家，本项目不经手 |
| 自定义端点 | 支持任何 OpenAI 兼容地址，含本地 Ollama |

预置了智谱 / 硅基流动 / NVIDIA / DeepSeek 四家，选中即自动带出地址与模型名。

**防欠费**：内置已知免费 / 已知付费型号名单。
选到付费型号（如 `glm-5.3`、`deepseek-chat`）会**弹确认框**，不点确认就不发送；
不认识的型号会明说「无法判断」，不假装免费。
名单核对于 2026-10-11，会过时——**是否扣费以服务商官网为准**。

## 手机上写码（移动端键条）

手机输入法**没有 Tab、Ctrl、Esc、方向键** —— 一行像样的代码都写不完整。
所以触摸设备上会自动出现一条底部键条，把这些键补上：

| 分组 | 内容 |
|---|---|
| 编辑 | Tab（缩进）、四个方向键、退格、换行（自动继承上一行缩进） |
| 符号 | `{} () [] ; : = < > & \| ! " ' # / \ _ + - * . , $` |
| 命令 | 全选 / 复制 / 剪切 / 粘贴 / 撤销 / 保存 / 运行 / Esc |

几个设计上的取舍：

- **点键不会让输入框失焦**。一旦失焦光标就没了、手机键盘还会收起，
  等于点一下断一次思路。所以按下时一律阻止默认行为。
- **只在触摸设备出现**，桌面有物理键盘时不显示（细腻指针自动隐藏）。
- **可收起**，收起后只留一条把手，状态记在本机。
- **避开 iPhone 底部横条**（`safe-area-inset-bottom`），否则最后一排点不到。
- Tab 用的是**当前文件的缩进单元**，不是硬编码空格。

## 装到桌面或手机（PWA）

装好是独立窗口，**断网也能写、能跑**。

| 平台 | 做法 |
|---|---|
| 桌面（Win / macOS / Linux） | Chrome 或 Edge 打开，点地址栏安装图标；或进编辑器后点顶栏「安装」 |
| iPhone | **Safari** 打开 → 分享 → 添加到主屏幕 |
| Android | Chrome 菜单 → 安装应用 |

安装只影响"怎么打开"，**不改变数据存放位置**——文件依然只在本机。
离线可用范围：JavaScript、HTML、Python 子集、C/C++ 子集。
按需下载的运行时第一次要联网，下完也缓存。

## 已知限制

- **死循环**：JavaScript 在主线程执行，没有抢占机制，
  陷入无限循环会卡住页面，需要关闭标签页。
  两个自研子集与 Worker 里的运行时带步数 / 超时上限，能被掐断。
  输出超过 800 行会自动暂停并提示。
- **按需运行时的执行链路未经真机验证**：六种语言一次都没真跑过
  （开发环境访问 Release 下载被网络策略挡住，返回 403）。
  SQLite 与 CPython 用的是公开稳定 API；Lua / Ruby / PHP 的胶水导出形状未在此环境确认，
  对不上时会报出实际的导出清单而不是静默失败。
- **Ruby 与 C++ 走动态 `import()`**：`ruby-wasi.js` 与 `cpp-index.js` 都是 ESM，
  `importScripts` 加载不了，改用 Worker 内的动态 `import()`。这两条路径**未真机验证**。
- **C++ 首次编译很重**：clang.wasm 43 MB + lld.wasm 23 MB + sysroot.tar 29 MB，
  约 95 MB，且要把 sysroot 解压进内存文件系统。请预留带宽与内存。
- **用 `file://` 双击打开时 Worker 会被拒绝**，按需下载的几种语言跑不起来。
  请在仓库目录执行 `python3 server.py`，然后访问 `http://localhost:8000/`。
  本地起服务与线上访问走的是同一份实现，仅来源不同。
- **单文件不宜过大**：着色与行号是全量渲染的，
  几 MB 级的单文件会明显变卡。
- **浏览器要求**：需要支持 IndexedDB 与 ES2020。
  导入压缩过的 ZIP 需要浏览器支持 `DecompressionStream`
  （未压缩的 ZIP 不受此限制）。

## 部署

GitHub Pages 免费版，只托管静态文件：没有后端、没有构建步骤、没有环境变量。
推送到 `main` 分支后由工作流自动发布。

因为是纯静态站点，`file://` 直接打开与 Pages 线上访问走的是同一份实现。

## 目录结构

```
index.html          页面骨架（含自绘 SVG 图标）
css/style.css       样式与深浅两套配色变量
js/util.js          通用工具、模态框、右键菜单
js/store.js         偏好设置 + IndexedDB 薄封装
js/fs.js            虚拟文件系统、ZIP 读写
js/highlight.js     手写语法着色
js/editor.js        编辑内核（输入、缩进、撤销栈）
js/runner.js        本地执行与预览、各运行时注入脚本
js/langs.js         语言注册表：谁能跑、怎么跑、属于哪一档
js/runtime.js       按需下载：进度、SHA-256 校验、缓存、Worker 隔离
js/pylite.js        Python 子集解释器（自研，分词 → AST → 树遍历）
js/cpplite.js       C/C++ 子集解释器（自研）
js/tree.js          文件树与工程内搜索
js/ui.js            标签栏、面板、命令面板
js/app.js           启动与装配
js/runtimes.js      按需运行时的主线程侧（起 Worker、转发、进度）
js/rt-worker.js     Worker 侧：加载与执行各运行时（classic + 动态 import）
server.py           本地静态服务（file:// 下 Worker 被拒时的退路）
```
