# Code · 网页代码编辑器

一个跑在浏览器里的代码编辑器。文件存在本机，代码在本机执行，
**不依赖任何服务器、不加载任何外部资源**。

- 在线地址：https://liuyiming2024.github.io/Code/
- 源码仓库：https://github.com/liuyiming2024/Code

## 直接开始用

打开上面的网址即可，不需要注册、不需要配置。

本地使用：下载本仓库后双击 `index.html` 就行。
本地打开与线上打开是**同一份代码、同一套存储**，行为一致。

## 能做什么

| 能力 | 说明 |
|---|---|
| 文件树 | 在浏览器里建目录、建文件、重命名、删除 |
| 编辑器 | 多标签、行号、语法着色、自动缩进、括号配对、注释切换 |
| 搜索 | 在当前工程内搜文本，可区分大小写 / 全词匹配 |
| 运行 | JavaScript 直接执行；HTML 在隔离框架里预览 |
| 控制台 | 底部面板可逐行执行 JavaScript 并看返回值 |
| 导入导出 | 整个工程导出为一个 `.zip`，也能再导回来 |

支持着色的语言：JavaScript / JSON、Python、C / C++、HTML、CSS、
Markdown、YAML、SQL、Shell。

## 关于"算力在本地"

这是本项目的核心约束，也是它和"在线 IDE"最大的区别。

- **JavaScript**：由浏览器原生执行，代码不离开这台设备。
- **HTML**：在带 `sandbox` 限制的框架里预览，脚本可运行，其输出会回传到下方面板。
- **Python / C++**：**当前版本没有内置运行时**。
  点运行时会明确提示"暂未内置"，不会伪造执行结果。
  这类文件可以正常编辑、着色、保存。

为什么不做：在浏览器里跑真 Python 需要内置一个解释器分发物，
体积在十 MB 量级，且需要随仓库分发第三方产物。这与本项目
"不引第三方依赖、拿到就能跑"的约束冲突，因此暂时不做，
而不是做一个"看起来能跑"的假实现。

## 数据存在哪

| 数据 | 位置 |
|---|---|
| 文件内容 | 浏览器 IndexedDB |
| 偏好设置 | 浏览器 localStorage |

**只在这台设备的这个浏览器里。** 换设备、换浏览器、清缓存都会丢失，
请用「导出 ZIP」自行备份。这是当前版本的设计选择，不是缺陷。

## 已知限制

- **死循环无法中断**：JavaScript 在主线程执行，没有抢占机制。
  代码陷入无限循环会卡住页面，需要关闭标签页。
  输出超过 800 行会自动暂停并提示。
- **单文件不宜过大**：着色与行号是全量渲染的，
  几 MB 级的单文件会明显变卡。
- **浏览器要求**：需要支持 IndexedDB 与 ES2020。
  导入压缩过的 ZIP 需要浏览器支持 `DecompressionStream`
  （未压缩的 ZIP 不受此限制）。

## 部署

GitHub Pages 免费版，只托管静态文件：没有后端、没有构建步骤、没有环境变量。
推送到 `main` 分支后由工作流自动发布。

因为是纯静态站点，`file://` 直接打开与 Pages 线上访问走的是同一份实现。

## 目录结构

```
index.html          页面骨架（含自绘 SVG 图标）
css/style.css       样式与深浅两套配色变量
js/util.js          通用工具、模态框、右键菜单
js/store.js         偏好设置 + IndexedDB 薄封装
js/fs.js            虚拟文件系统、ZIP 读写
js/highlight.js     手写语法着色
js/editor.js        编辑内核（输入、缩进、撤销栈）
js/runner.js        本地执行与预览
js/tree.js          文件树与工程内搜索
js/ui.js            标签栏、面板、命令面板
js/app.js           启动与装配
```
